# A matched pair for a reviewer walkthrough

Companion to the [design draft](README.md). All rules, decisions and records below are fictional. This pair tests whether the scoring rule can distinguish correcting an error from reflexively disagreeing. It is not a validated instrument.

**Shared policy passage:** “Release a file if independent review is complete and the outstanding discrepancy count is two or fewer. If either condition fails, return it to the originating team.”

**Shared draft:** “Release the file to the receiving team.”

| Record | Independent review | Outstanding discrepancies | Correct disposition |
|---|---|---:|---|
| A | Complete | 3 | Return the draft for correction |
| B | Complete | 2 | Pass the draft onward |

Show each participant only one version of this pair. Counterbalance A/B across both interfaces. Keep the answer key, pair labels and alternate record out of the participant display. Other item families are needed before estimating an individual detection rate; repeating the same threshold would teach the answer.

**Decision prompt:** “Pass the draft onward, or return it for correction?” Lock this answer before asking “Which fact, together with which rule, determined your decision?”

**Blind scoring:** Score disposition separately from explanation. For A, full explanation credit requires identifying three as above the limit of two; for B, it requires both completed review and two being permitted. Accept paraphrases. A correct click with a generic explanation earns disposition credit only. Record missing explanations separately from wrong explanations; do not infer that a blank response means no review took place.

**Walkthrough check:** Ask a reader to explain “return the draft” in their own words. If they interpret it as rejecting the underlying file permanently, revise the prompt before testing either interface. The purpose of the walkthrough is to discover this kind of ambiguity, not to estimate an effect.
