# When a clear proposal is not adopted

**Bounded public-record contrast · November 9, 2026**

The [November 7 reading](review-to-implementation-2026-11-07.md) followed one
request to a compatible change. This unit deliberately examines a different
disposition, rather than collecting another successful implementation.

## What the sources establish

[PEP 677](https://peps.python.org/pep-0677/) records a rejected syntax proposal.
The [decision notice](https://mail.python.org/archives/list/python-dev@python.org/message/NHCLHCU2XCWTBGF732WESMN42YYVKOXB/)
acknowledges the proposal's clarity, but weighs shared complexity and future
design constraints against its local benefits. These are recorded reasons,
not measured costs or independent comprehension results.

Readiness also needs its own evidence. A [January 21 draft](https://github.com/python/peps/blob/113e4907014a8b201d2367aea9644498eb577b04/pep-0677.rst#L1150-L1193)
reports a parser/AST prototype while runtime behavior remains unfinished.
The historical version prevents us from silently treating a prototype as a
complete, ready-to-adopt implementation. No prototype code was executed here.

## What this changes in the reading question

| Work unit | Disposition evidence | Main limit |
|---|---|---|
| Earlier pandas error-message request | Reply and a compatible merged artifact | No independent evidence of downstream benefit |
| PEP 677 syntax proposal | Public decision notice and official rejection status | Claimed clarity is not universal comprehension; implementation readiness was partial |

These are different projects and decision scales, not a matched counterfactual.
The useful contrast is that an organization can process a proposal and decide
against adopting it. Recording only whether a suggestion was implemented would
collapse that disposition into the same category as a request nobody received.

For future observation, keep the requested action and the decision criterion
separate from the disposition. Ask what evidence supports each step: receipt,
understanding, readiness, authority for this action, a decision, and a relevant
outcome. An explicit refusal may complete a decision process without completing
the proponent's desired change. Whether that refusal serves a worthwhile goal
requires further evidence and value judgments.
